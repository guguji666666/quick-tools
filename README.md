# Quick Tools

一个准备部署到 GitHub Pages 的浏览器工具集合。左侧选择工具，右侧使用工具。

## 项目功能简介

- YAML Diff：语义比对两个 YAML 文档，忽略空行、键顺序、缩进、引号、注释等格式噪音。
- YAML Diff 支持多个会话同时保留输入和结果。
- YAML Diff 支持关闭会话后立即撤销。
- IT Tools：内嵌常用开发转换工具，包含 JSON、Base64、URL、SHA-256、UUID、时间戳和文本大小写。
- 总览工具和 IT Tools 内嵌工具都支持拖拽排序。
- 支持中文和英文界面切换。

## 技术架构

- 无构建静态页面，适合 GitHub Pages。
- YAML 解析和语义比对运行在 Web Worker，避免大文件卡住主界面。
- YAML 解析使用 `js-yaml@4.1.0` 浏览器版本。
- 差异结果直接显示在左右内容区，接近 GitHub diff 的阅读方式。
- IT Tools 的小工具直接运行在当前页面内，不上传用户输入。
- 工具顺序保存在浏览器本地状态，只保存工具 id。
- 语言切换使用浏览器本地状态保存，不引入构建流程。

## 本地运行

```bash
npm run dev
```

打开：

```text
http://127.0.0.1:5173
```

不要直接用 `file://` 打开做比对；示例按钮可用，但 YAML 解析线程需要 HTTP 环境。

## 部署命令

当前不需要构建，直接把仓库推到 GitHub Pages 可访问的分支即可。

## 已完成功能

- 工具聚合页面骨架。
- YAML Diff 首版。
- Worker 后台比对，页面保持可操作。
- `file://` 打开时给出明确提示，避免误以为按钮失效。
- YAML Diff 多会话：可新建、切换、关闭会话，每个会话独立保存输入和比对结果。
- YAML Diff 关闭会话后可撤销恢复，降低误删风险。
- YAML Diff 比对后左右输入区原地切成对照结果，按真实内容差异标注新增、删除、修改。
- IT Tools 内嵌工具集，支持 JSON 格式化/压缩、Base64 编码/解码、URL 编码/解码、SHA-256、UUID、时间戳转换和文本大小写转换。
- 总览工具列表和 IT Tools 内嵌工具列表支持拖拽排序并记住顺序。
- 中英文界面切换。
- 本地测试脚本。
